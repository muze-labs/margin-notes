# Contributing

The project is not yet open for general contributions, and no licence has been selected. Discussion and experiments should remain small and tied to the active milestone.

A useful change should:

- solve a concrete reference-application problem;
- preserve the local end-to-end path;
- include tests or an observable acceptance case;
- update design documents when it changes an assumption;
- add a book note when it exposes a teachable boundary;
- avoid broad abstractions that have only one hypothetical caller.

Before proposing a major API, add the problem to `docs/OPEN_QUESTIONS.md` or a decision entry describing the evidence.
